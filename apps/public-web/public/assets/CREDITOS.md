# Créditos de las imágenes de `public-web`

Ficha de procedencia de cada fotografía servida desde `/assets/`, según
[`02` §Imágenes](../../../../../docs/especificacion/02-landing-y-panel.md#imágenes): autor, origen,
licencia y fecha de descarga. Ninguna imagen se enlaza en caliente desde un banco, un acortador ni
un CDN de terceros: todas están descargadas en este repositorio.

Las rutas de datos (`/assets/sedes/<slug>-fachada.jpg` y
`/assets/habitaciones/<slug>-<individual|doble>-<n>.jpg`) son las que fijan
`back-hotel-presentacion-real` §5 y `back-inventory-imagenes-producto` §5.

El fallback neutro `/assets/fallback.svg` es un SVG propio de esta app: no representa ninguna
fotografía y no necesita ficha de terceros.
